# Hackathon 2019 — Community Help Platform

React + Apollo GraphQL app for posting and offering help. Built with Create React App, Ant Design, and maps.

## Prerequisites

- Node.js and Yarn
- Running GraphQL backend

## Setup

```bash
cp .env.example .env   # set REACT_APP_URL_GRAPHQL
yarn install
```

## Run

```bash
yarn start
```

Dev server runs at http://localhost:3000

## Docker

```bash
docker-compose up --build
```

App runs at http://localhost:3030
